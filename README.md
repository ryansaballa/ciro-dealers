# CIRO Dealer Explorer

An interactive React application that visualizes CIRO-regulated dealers across Canada.

## Features

- Interactive map
- Dealer search
- Province filtering
- Category filtering
- Dealer details
- Statistics dashboard

## Data Source

Canadian Investment Regulatory Organization (CIRO)
Dealers We Regulate Directory

## Tech Stack

- React
- Vite
- Leaflet
- Tailwind CSS
- Node.js
- Cheerio
